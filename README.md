# Thushan Vithana — Portfolio

A premium dark portfolio for a software engineer: glassmorphism over deep
black, electric-blue → cyan → violet gradients, and motion everywhere it
earns its place.

## Stack

- **Next.js 15** (App Router) + **TypeScript**
- **Tailwind CSS 4** — design tokens in `app/globals.css` (`@theme`)
- **Framer Motion 12** — reveals, staggers, magnetic buttons, carousel
- **Lucide** icons · shadcn-style primitives (`components/ui`)
- Self-hosted variable fonts (Space Grotesk / Inter / JetBrains Mono) via `next/font/local`

## Structure

- `lib/data.ts` — **all content lives here** (bio, stats, skills, projects,
  experience, achievements, testimonials, links). Edit facts in one place.
- `components/` — one file per section (`hero`, `about`, `skills`,
  `projects`, `experience`, `achievements`, `tech-wall`, `github-stats`,
  `testimonials`, `contact`, `footer`) plus shared motion primitives in
  `components/motion/`.
- `components/ambient-background.tsx` — fixed grid + aurora blobs + canvas
  particle field behind every section (honours `prefers-reduced-motion`).
- `components/github-stats.tsx` — fetches live data client-side from the
  public GitHub API with a static fallback snapshot; the contribution graph
  hides itself if the API is unreachable.

## Assets

Generated by scripts (no design tools needed):

```bash
node scripts/generate-assets.mjs   # project covers, favicon, OG image
node scripts/generate-resume.mjs   # placeholder resume PDF
```

Replace `public/projects/<slug>.svg` with real screenshots and
`public/Thushan-Vithana-Resume.pdf` with the real resume whenever ready —
same filenames, no code changes.

## Run

```bash
npm install
npm run dev      # dev server
npm run build    # production build
npm start        # serve the production build
```

## Deploy

Built for Vercel: framework preset **Next.js**, zero config.
